Slow PC: 5 checks you can do yourself

Before calling a technician, here are five checks you can do yourself in a few minutes, on Windows and on Mac.

Updated September 2026

1. Really restart

On Windows, «Shut down» often doesn't fully turn off the system, so that it starts faster. Use Restart: it frees up memory and completes pending updates.

2. Check your disk space

With an almost full disk, everything slows down. On Windows open Settings › System › Storage and turn on Storage Sense. On Mac open System Settings › General › Storage. Try to keep at least 10–15% of the disk free.

3. Remove unnecessary start-up programs

Many programs start by themselves when you turn on the PC. On Windows open Task Manager with Ctrl + Shift + Esc, go to «Startup apps» and disable the ones you don't need. On Mac look in System Settings › General › Login Items.

If in doubt, don't disable antivirus, audio drivers or programs you don't recognise: ask me first.

4. Install updates

On Windows open Settings › Windows Update, on Mac System Settings › General › Software Update. Updates fix bugs and security problems.

5. Check for viruses and browser extensions

On Windows open Windows Security › Virus & threat protection and run a scan. Then look at your browser extensions and remove any you didn't install yourself.

If it's still slow

If your computer is still slow after these checks, the cause may be deeper: conflicting programs, unwanted software, a disk that's failing. Sometimes, on a PC that's a few years old, an SSD changes everything: that's a job to be done on site, but I'll tell you first whether it's worth it.
